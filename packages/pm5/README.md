# @ergometer/pm5

Concept2 PM5 protocol for [react-native-ergometer](https://github.com/sergey-g-s/react-native-ergometer): Bluetooth UUIDs, advertisement parsing, CSAFE workout frames, workout data and summary parsing, and the firmware lookup. It is installed together with `react-native-ergometer`; use that package in your app.
